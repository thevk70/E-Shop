# 🛒 e-shop

A modern full-stack E-Commerce platform built with the MERN Stack featuring secure authentication, Stripe payment integration, inventory management, notifications, and a professional admin dashboard.

**---**

## 🚀 Live Features

### 👤 User Features

- User Registration & Login

- Browse Products

- Product Image Carousel

- Add To Cart

- Update Cart Quantity

- Secure Stripe Checkout

- Order History

- User Notifications

- Profile Settings

- Responsive Design

### 🤖 AI+ Shopping Assistant

- AI-powered shopping assistant integrated into the E-Shop

- Natural language product search and discovery

- Context-aware product recommendations

- Product recommendations based on user requirements such as budget, category, and use case

- AI-powered product comparison and product-related questions

- Context-aware AI assistant on the product details page

- AI can understand the currently viewed product and answer questions about it

- Product specification assistance using stored product specifications

- AI-powered recommendation explanations

- Direct navigation from AI-recommended products to their product details page

- Movable floating AI+ chatbox

- Customer support intent detection

- Refund-related issue detection

- Support information provided based on detected support intent

- AI responses grounded in available product data to reduce hallucination

### 👨‍💼 Admin Features

- Dashboard Analytics

- Product Management

- Order Management

- Customer Management

- Notification Center

- Inventory Management

- Low Stock Alerts

- Out Of Stock Alerts

- Store Settings

- Revenue Tracking
